# AI Application Copilot

A full-stack web application that helps users generate tailored job application materials, including cover letters and common application responses.

## Tech Stack
- React + Vite
- Node.js + Express
- MongoDB
- JWT Authentication

## Features
- User authentication
- Protected dashboard
- Reusable professional profile
- Job description input
- AI-generated cover letters and application answers

## Project Structure
- `/frontend` - React client
- `/backend` - Express API

## Getting Started

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
